# Tennis Center Analytics

Учебный pet-проект: аналитика клиентской активности теннисного центра.
Демонстрирует навыки работы с PostgreSQL, ETL-процессами, DWH-моделированием
и построением витрин данных.

## Что делает проект

- Генерирует тестовые данные для теннисного центра (клиенты, абонементы, договоры, бронирования).
- Переносит данные из операционного слоя (staging) в хранилище (dwh).
- Строит аналитические витрины (marts): новые клиенты, удержание, загруженность кортов.
- Предоставляет CRUD-операции: регистрация клиентов, оформление и продление договоров,
  бронирование кортов, отметка посещений.

## Стек технологий

- Python 3
- PostgreSQL
- psycopg2
- SQL (DDL, DML, CTE, оконные функции)

## Архитектура

Проект построен по трёхслойной схеме:

- **staging** — сырые данные из операционной системы;
- **dwh** — факты и измерения (dim_client, dim_subscription, dim_date, fact_contract, fact_booking);
- **marts** — готовые витрины для аналитики.

## Как запустить

1. Установить PostgreSQL и создать базу `tennis_center`.
2. Установить зависимости:
  pip install psycopg2-binary
3. Настроить подключение в файлах `generate_data.py`, `etl.py`, `generate_marts.py`, `operations.py`.
4. Выполнить по порядку:
  python generate_data.py
  python etl.py
  python generate_marts.py
5. Запустить консольный интерфейс:
   python cli.py

## Что реализовано

- Три аналитические витрины:
- `mart_new_clients` — новые клиенты по месяцам;
- `mart_client_retention` — удержание клиентов;
- `mart_court_load` — загруженность кортов.
- Консольное меню: поиск клиента, регистрация, оформление и продление договора,
бронирование корта, отметка посещения.
